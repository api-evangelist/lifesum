## API status

Lifesum publishes **no public API** at this time. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI description, no OAuth surface, and no `/.well-known/`
discovery documents. Requests for an unmatched path on lifesum.com return an HTTP 200
single-page-app HTML shell rather than a 404, so status codes alone are not evidence
that a developer resource exists. Agents should not attempt to construct Lifesum API
calls; there is no documented public endpoint to call.
